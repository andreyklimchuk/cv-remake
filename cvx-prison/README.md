# RE: Code Veronica X — Тюрьма (браузерный прототип)

Откройте `index.html` (можно прямо с диска или через GitHub Pages). Ресурсы извлечены из PS3-версии игры.

## Управление
- W/S или ↑/↓ — вперёд/назад, A/D или ←/→ — поворот, Shift — бег
- E / Пробел / Enter — действие, Tab — предметы, Esc — отмена, F1 — отладка
- C — переключение камеры: фиксированные ракурсы оригинала / камера от плеча (как в RE2 Remake)
  - в режиме от плеча: мышь (клик по экрану захватывает курсор) или ←/→ — обзор, A/D — шаг вбок
- F / ПКМ / Ctrl — приготовить нож (если он экипирован), ЛКМ / Пробел — удар
- Зажигалка, выбранная в инвентаре, видна в руке Клэр

## Структура
- `data/part*.js` — ресурсы (glb/текстуры/звуки), `data/mv_000_*.js` — вступительный ролик
- `src-ts/` — исходники на TypeScript (Vite + three.js): `npm i && npm run build && node scripts/split.mjs`
- `tools/` — конвертеры форматов игры (ARC, TEX, Ninja MDL → glb и т.д.)
