# Blender-пайплайн персонажей (Python / bpy 5.1)

Все модели генерируются кодом из этих скриптов и сохраняются в `assets/blender/*.blend`
(с упакованными текстурами) + экспортируются в `src/assets/models/*.glb` для игры.

Требования: `pip install bpy==5.1.2` (Blender как Python-модуль) или запуск через
`blender -b -P script.py`. База анатомии — **Blender Studio Human Base Meshes v1.4.1 (CC0)**,
положить в `/data/assets_src/hbm/human-base-meshes-bundle-v1.4.1/human_base_meshes_bundle.blend`
(пути в `lib.py` при необходимости поправить).

| Скрипт | Что делает |
|---|---|
| `claire_s1.py` | тело (multires 1 для игры, multires 3 для запекания нормалей), скелет с игровыми именами костей, heat-weights |
| `claire_shapekeys.py` | shape keys: blink, pain, grip_L, grip_R |
| `claire_s2.py` | одежда: майка, байкерская кожаная куртка (длинные рукава, чуть подтянутые; лацканы, асимметричная молния, манжеты на молнии), джинсы, ботинки, перчатки без пальцев, ремень + пряжка, подсумки, набедренная кобура; high-poly копии со складками |
| `claire_s3.py` | волосы: скальп + ~400 hair cards, хвост на 4 костях, ресницы |
| `claire_s4.py` | UV, запекание (Cycles): position/normal/AO/normal-from-high, процедурные PBR-текстуры (кожа с порами/веснушками, деним, кожа, швы, тёмно-красно-коричневая кожа с зерном, швами и карманами на молнии, принт валькирии на спине), атлас волос, экспорт GLB |
| `zombie.py` | `ZV=prisoner|guard`: мужская база, скелет по топологическому соответствию, рваная одежда, раны, кровь, вены, мутные глаза — один атлас 2K |
| `valkyrie.py` | рисует принт «Валькирия» с лентой «LET ME LIVE» (PIL) для спины куртки → work/valkyrie.png (до claire_s4) |
| `hs.py` | хелперы hard-surface моделирования (материалы, примитивы, lathe, декали, этикетки) |
| `items.py` | лежачие предметы: коробки патронов, травы в горшках, ключ-карта, огнетушитель, эмблема, пластина, маховик, баночки пороха A/B/C и Bow Gun Powder, разрывные/зажигательные болты, станок Reloading Tool, подсумок Side Pack и т.д. → `item_<id>.glb` |
| `props2.py` | реквизит для улицы и дворца: балюстрада, столбик с канделябром, люстра, колонна, круглое окно-розетка с пентаграммой, деревянная дверь, бра, знамя, портрет Алексии, фонарь, перила моста, мешки с песком, табличка Umbrella Military Training Facility, оконная рама, статуя ястреба, ваза, кованые ворота → `prop_<name>.glb` |
| `setup_env.sh` | переустанавливает bpy 5.1.2 + mesa (нужно перед запуском скриптов в новой сессии) |
| `weapons2.py` | дробовик M3, MP5, Python, гранатомёт, арбалет, линейный ускоритель → `weapon_*.glb` |
| `props.py` | пропсы локаций: кровати, унитазы, шкафчики, столы, машинка, сундук, сейф, шкатулка, трубы, стеллажи, картины… → `prop_*.glb` |
| `icons.py` | иконки инвентаря в стиле RE: Cycles-рендер моделей на тёмно-синем фоне → `src/assets/icons/<id>.jpg` |
| `steve.py` | Стив Бернсайд: тело, жилет, майка, камуфляжные штаны, ботинки, чокер, напульсники, волосы (cap + cards), риг, запечённые PBR-текстуры → `steve.glb` (`TEXSIZE=2048`) |
| `creature.py` | Церберы и Бандерснэтч: метабол-скульпт, раны, зубы/когти/глаза, авто-веса, процедурное запекание → `enemy_<kind>.glb` (`CV=cerberus|bandersnatch TEXSIZE=2048`) |
| `weapons2.py` | M3, MP5, Python, гранатомёт, арбалет, линейная пушка, золотые Люгеры Эшфордов (`python3 weapons2.py luger` — только один) |
| `weapons.py` | hard-surface M9F (серрации, насечка рукояти, прицелы с точками, курок, предохранитель) и боевой нож |

Порядок: `claire_s1 → claire_s2 → claire_s3 → TEXSIZE=2048 claire_s4`, затем `zombie.py` (для двух вариантов) и `weapons.py`, `weapons2.py`, `items.py`, `props.py`, `props2.py`, затем `steve.py`, `CV=cerberus creature.py`, `CV=bandersnatch creature.py`, `icons.py`.
